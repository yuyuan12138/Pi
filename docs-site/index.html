我的 Pi Agent 架构

一套「一个项目一个主对话」的代理工作体系：主对话只派工、决策、验收；干活的是干净上下文的子代理；多项目由确定性协调器路由。

一图流架构

            用户（需求 · 决策 · 最终验收）
                     │
   ┌─────────────────▼──────────────────┐
   │   主对话 primary（每项目一个）        │
   │   只做：拆解派工 / 决策 / 验收 / 集成 │
   └───┬──────────┬──────────┬─────────┘
     fork      subagent   subagent    observational
   （带上下文）（干净上下文）（干净上下文）   memory
       ▼          ▼          ▼             ▼
  实现调试    顾问/评审   9 类角色 worker   会话内记忆

  项目A主对话 ─┐
  项目B主对话 ─┼─▶ pi-project-coordinator
  项目C主对话 ─┘   registry · 确定性路由 · 单写队列
