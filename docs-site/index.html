PiAgents: A Reproducible Agent Operating System

An agent operating system organized as plain-text rules + templates: the primary conversation only dispatches work, decides, and accepts deliverables; the actual work is done by clean-context subagents; the entire kernel is Markdown plus three scripts, engine-agnostic — install pi and it runs, and the ideas port to any agent framework. Three-step reproduction in the README. Chinese edition: zh/README.md（中文版）.

Reproduction in three steps (details in the README)

  • ① Install pi (or declare the ideas portable)
  • ② Copy three categories of text assets: global rules / 9 role templates / 3 scripts
  • ③ Walk a real example: send coder a filled-in task brief
