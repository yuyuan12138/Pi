PiAgents：一套可复现的「代理操作系统」

纯文本规则 + 模板组织的代理操作系统：主对话只派工、决策、验收；干活的是干净上下文的子代理；全部内核是 Markdown 与三个脚本，引擎无关——装 pi 即用，理念可移植到任何 agent 框架。三步复现见 README。

三步复现（详见 README）

  • ① 装 pi（或声明理念可移植）
  • ② 拷贝三类文本资产：全局规则 / 9 角色模板 / 3 个脚本
  • ③ 走一个真实例子：给 coder 发一份填好的任务书
