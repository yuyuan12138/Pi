# analyst skills

Entry point for the analyst role's specialization skills. Each file is a
concrete procedure, not a placeholder; they are promoted further into full
methodology as verified lessons accumulate in `../records/experience.md`.

## Files
- `metrics-design.md` — definitions, denominators, windows fixed before data.
- `ab-analysis.md` — run-count honesty, significance only from controlled runs.
- `cost-accounting.md` — token/cost tables with unit, period, basis, reconciliation.

## Read order
1. The specialization the brief names — read it first, fully.
2. `metrics-design.md` whenever a number will be produced at all — the
   definitions gate everything downstream.
3. The project's own analysis conventions (existing reports, metric
   registries) before computing.

## Standing rule
Proposal-only: analysis and recommendations, never code/doc edits, never
acceptance decisions. Never manufacture significance or precision — a
single-run comparison gets NO significance claims. No specialization skill
overrides this.
