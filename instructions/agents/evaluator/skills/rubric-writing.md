# Skill: rubric-writing (evaluator specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Anchored levels: each score level is described by an observable example, not an
  adjective ("fails to start" beats "poor").
- One dimension per criterion; weights set before scoring, never after seeing
  the results.
- A second pass on one artifact should land within one level; if not, the rubric
  is ambiguous — fix the rubric before trusting the score.
