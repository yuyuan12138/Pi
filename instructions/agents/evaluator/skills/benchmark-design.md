# Skill: benchmark-design (evaluator specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- A benchmark measures the claimed outcome, not effort or line count; the metric
  maps to the user-visible capability the brief names.
- Repeatable: fixed data, fixed seed where possible, variance reported across
  runs; a benchmark whose score cannot be reproduced is a finding, not a score.
- State the blind spots: what the benchmark cannot see must be listed with the
  result, so "passed" never reads as "done".
