# Skill: live-acceptance (evaluator specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Fresh runs against the real system built from the named source; cached or
  quoted scores are context, never evidence.
- Evidence = artifacts (logs, outputs, screenshots, run configs) stored at paths
  the parent can re-open; a number without an artifact is unverified.
- Record the environment (versions, config, data snapshot) with the run so the
  result is reproducible by a third party.
