# Skill: test-authoring (tester specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Tests fail for the stated reason first, then pass; one behavior per test with a one-sentence rationale.
- Anchor every fixed bug with a regression test that asserts the prior failure stays dead.
- Match the existing test framework and style; never introduce a second runner uninvited.
