# Skill: system-prompt-design (prompt-engineer specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Every clause earns its tokens: tie each addition to a named failure it
  prevents; delete clauses whose failure case cannot be named.
- One clause = one behavior; merged "and" clauses blur which part failed.
- Prefer positive, checkable instructions over negations of observed symptoms —
  but keep the boundary statements that mark trust lines verbatim.
