# curriculum-designer

Curriculum designer agent (ability-progression profile): ladder design,
prerequisite mapping, self-play task generation (Voyager-style). Proposes
curriculum nodes + gates; the engine applies them. Flagship workload: the
MC RSI advancement-tree ladder.

Layout: AGENTS.md = role definition and task-brief template; skills/ = entry
stub + specialization stubs; records/ = experience log and task records.
