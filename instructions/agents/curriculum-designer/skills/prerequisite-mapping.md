# Skill: prerequisite-mapping (curriculum-designer specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Every prerequisite claim cites capability evidence: a record, run artifact, or
  prior gate pass — aspiration is labeled as an assumption.
- Map the graph before ordering: cycles and orphan nodes are design errors to
  fix, not runtime surprises.
- When evidence is thin, insert a diagnostic node (cheap probe run) before the
  dependent rung instead of assuming the capability.
