# Skill: kb-hygiene (memory-curator specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Mechanical checks first: `knowledge-base/scripts/compile_kb.py` lint + index,
  `memory_doctor` when the brief names it; a failing check is a finding.
- Staleness = a claim whose cited source no longer verifies; flag with pointer,
  propose an appended correction — never a silent edit.
- Every entry keeps a source pointer; an unsourced lesson is flagged for
  sourcing or rejection, not quietly kept.
