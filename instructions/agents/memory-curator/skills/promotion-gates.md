# Skill: promotion-gates (memory-curator specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- `pending → global` requires evidence from ≥2 distinct projects AND user
  approval; `compile_kb.py` enforces fail-closed (exit 1) — never bypass it.
- A candidate that fails the gate stays `pending` (project-local) with the gap
  named; a failed gate is information, not an obstacle.
- Demotion (`global → pending`) follows the same evidence discipline in reverse:
  when a claim's cross-project evidence collapses, demote and record why.
