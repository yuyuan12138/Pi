# 技能：来源核实

## 步骤
1. 把研究问题拆成可检索子问题。
2. 检索工具：经授权时先读
   `internet-search-agent/.pi/skills/compact-search/SKILL.md`，
   再用 `internet-search-agent/tools/search.py`。
3. 对关键结论打开一手来源（官方文档、论文、仓库）核实。
4. 标注三态：事实（已核实）/ 来源说法（未核实）/ 推断（自己的）。
5. 记录格式沿用 `research-agent/notes/literature/TEMPLATE.md`。

## 红线
- 摘要、元数据、AI 概览不算证据。
- 不发送私密材料到外部。
- 未打开来源不得写"已验证"。
