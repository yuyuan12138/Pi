# Skill: source verification

## Steps
1. Decompose the research question into searchable sub-questions.
2. Search tool: when authorized, first read
   `internet-search-agent/.pi/skills/compact-search/SKILL.md`, then use
   `internet-search-agent/tools/search.py`.
3. Open primary sources (official docs, papers, repositories) for key claims.
4. Label claims: verified fact / source claim / your inference.
5. Follow `research-agent/notes/literature/TEMPLATE.md` for durable notes.

## Red lines
- Snippets, metadata, and AI overviews are not evidence.
- Never send private material to external services.
- Never write "verified" without opening the source.
