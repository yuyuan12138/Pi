# Skill: claims-audit (researcher specialization)

> Minimum bar plus operating procedure; promoted further into full methodology
> as verified lessons accumulate in `../records/experience.md`.

## Procedure
1. State the contested claim precisely (who asserts what, where you found
   the assertion) — an imprecise claim cannot be audited.
2. Identify what a primary source for this claim would be: the spec/RFC,
   the paper, the repo's code or release notes, the official docs page.
3. Open the primary source and locate the exact passage; quote it with
   section/line + URL — the passage, not the page title, is the evidence.
4. Classify the outcome: SUPPORTED (the passage says it) / CONTRADICTED
   (a passage says otherwise — quote it) / NOT_FOUND (the primary is
   silent — say where you looked).
5. Label every step in the audit trail: verified fact (the passage you
   read) / source claim (what the source asserts but you did not
   independently verify) / inference (what you conclude from the
   passage).
6. If the claim traces through a chain of sources, audit the weakest link
   first and report exactly where the chain breaks.

## Anti-patterns
- Confirming a claim from a secondary source that itself cites nothing.
- "Consistent with" reported as "confirmed".
