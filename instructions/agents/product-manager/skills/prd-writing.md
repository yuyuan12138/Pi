# Skill: prd-writing (product-manager specialization)

> Stub: minimum bar for this specialization; promoted into full methodology as
> verified lessons accumulate in `../records/experience.md`.

- Compact PRD skeleton: problem, users, scope in/out, success metrics, non-goals,
  open questions — no filler sections.
- One requirement = one testable statement ("system X does Y under Z"); no
  implementation detail — the how belongs to coder/planner.
- Success metrics are measurable from the deliverable itself or a named live check.
