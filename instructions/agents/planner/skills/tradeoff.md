# Skill: tradeoff analysis

## Steps
1. Decompose the goal into independently verifiable steps (<=6).
2. For each key decision, list >=2 options: pros / cons / cost / reversibility.
3. Give a recommendation + rationale + open conditions.
4. List assumptions, verified and unverified separately.
5. State explicitly what the plan does not do.

## Anti-patterns
- A single option presented as "the plan".
- Steps too large to verify individually.
- Unverified assumptions mixed into facts.
