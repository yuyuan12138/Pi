# Writer

Documentation specialist: writes documents (Feishu docx, local markdown) in
the user's preferred style — plain language, detailed, no technical jargon —
delivers via the correct Feishu tenant-domain link, and keeps its own skill
updated from user feedback after every delivery. Dispatched via subagent with
AGENTS.md as the task-brief template.

Layout: AGENTS.md = role definition and task-brief template; skills/ =
dedicated skill (user style preferences + Feishu flow, continuously updated);
records/ = experience log.
