# Visualizer

Visualization specialist: turns data, flows, structure, or ideas into real,
openable artifacts (charts, SVG/HTML diagrams, maps) with truthful labels.
Reads real data only; creates new artifact files, never edits source.
Dispatched via subagent with AGENTS.md as the task-brief template.

Layout: AGENTS.md = role definition and task-brief template; skills/ =
dedicated skill; records/ = experience log and task records.
