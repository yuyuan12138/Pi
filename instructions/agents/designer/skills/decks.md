# Skill: decks (designer specialization)

> Minimum bar plus operating procedure; promoted further into full methodology
> as verified lessons accumulate in `../records/experience.md`.

## Procedure
1. One message per slide: write the headline as the takeaway sentence,
   then add the minimum body that supports it; a slide that needs a
   paragraph is a document, not a slide.
2. Deck structure: answer first (the title states the conclusion), then
   the evidence chain, then appendix for detail — the deck renders as
   evidence, not a description of evidence.
3. Data slides: one chart per question, axes/units labeled, the takeaway
   in the headline ("churn halved after v2"), not buried in a legend.
4. Apply the brand token set (`brand-systems.md`); slides by different
   authors must be visually indistinguishable in style.
5. Self-verify rendered: open the deck, squint test per slide (3
   hierarchy levels), check text overflow at the smallest supported
   screen, and contrast under projected-bright settings.
6. Deliver rendered files (PDF/images) alongside sources; a deck that
   only opens in the authoring tool has not been delivered.

## Anti-patterns
- Walls of bullets read aloud verbatim.
- Chart screenshots with unreadable axis labels.
